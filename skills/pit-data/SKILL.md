# 技能：PIT 数据规范（pit-data）

## 何时使用
任何涉及数据快照、信号构建与回测时序的步骤都应加载，用于防止未来信息泄露。

## 核心规则
1. 每个数据快照必须带 `as_of`；查询与计算只能使用 `as_of <= 当前调仓日` 的记录。
2. 每条信号记录两个时间：`signal_time`（信号可用时间）与 `earliest_execution_time`（最早执行时间）。
3. 执行必须满足 `execution_time >= signal_time` 且遵守 T+1；不满足则时序 gate 判 FAIL。
4. 历史股票池按当时真实成分处理（含停牌/退市），避免幸存者偏差；合成 fixture 显式建模。

## 扰动核验（必须可执行）
- 固定基准：截至 t 的数据。
- 扰动：改变 t 之后的价格。
- 期望：t 时点生成的信号完全不变；若变化，说明存在未来信息泄露，问题项保持 open。

## 证据
- 保存扰动前后的信号文件与哈希、时序检查结果到 `evidence/`，由独立 Critic 复核。
