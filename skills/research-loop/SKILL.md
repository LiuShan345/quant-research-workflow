# 技能：量化研究循环（research-loop）

## 何时使用
每次启动一个研究案例（月度调仓、新想法、新数据版本）时加载，保证不同案例的口径与产物位置一致。

## 标准流程
1. 读取 `config/config.json` 与当前 `request.json`，确认 `as_of` 与参数（lookback、top_k、成本）。
2. **数据**：生成/读取带日期快照，跑数据质量检查，计算哈希后存入 `data/raw/`。
3. **信号**：基于截至每个调仓日的数据计算动量，写入信号可用时间，存 `data/processed/`。
4. **回测**：信号可用之后交易，扣成本、T+1，输出净值、交易记录与指标到 `output/`。
5. **稳健性**：改变 lookback/top_k、扰动未来价格、压力测试成本，结论汇总到 `evidence/`。
6. **组合**：等权构建并检查限额，形成待批准清单。

## 产物规范
- 每个产物记录：路径、sha256、as_of；数值一律由 Python 计算并保存脚本。
- 缺失值标 n/a，禁止填 0；任何检查失败不得进入下一阶段。

## 口径一致性
- 指标公式、单位、成本、T+1 规则以本技能与 `config/` 为准，不同案例不得各自更改。
